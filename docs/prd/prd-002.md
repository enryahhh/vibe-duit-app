# PRD-002: Financial Goal Setting & Savings Recommendation Engine

**Version:** 1.0  
**Status:** Draft  
**Owner:** Product Manager  
**Priority:** P0 (Must-have)  
**Dependencies:** PRD-001 (transaction data, account balances)

---

## 1. Objective

Empower users to set concrete financial goals (e.g., emergency fund, vacation, gadget purchase) and automatically calculate how much they need to set aside each month, based on their actual historical income/expense patterns, to achieve those goals by a target date.

## 2. User Stories

- As a user, I want to create a goal named “Emergency Fund” with a target amount of $5,000 and a deadline of 12 months, so I know how much to save monthly.
- As a user, I want the app to recommend a realistic monthly saving amount by analyzing my past cash flow, not just divide the target by months.
- As a user, I want to see my progress toward each goal and what percentage I’ve achieved.
- As a user, I want to adjust a goal’s target amount or deadline and see the updated plan.

## 3. Functional Requirements

### 3.1 Goal CRUD

- **FR2.1:** Users can create, edit, pause, and delete goals. Each goal contains:
    
    - Goal name
    - Target amount
    - Current saved amount (auto-updated when user manually logs progress or when linked to a dedicated savings account)
    - Deadline (date) – optional, can have no deadline for open-ended goals.
    - Priority (High, Medium, Low) for sorting.
    - Linked Account (optional) – a specific savings account whose balance contributes to the goal.

### 3.2 Goal Input Form

See Section 4.
### 3.3 Monthly Savings Recommendation Engine

- **FR2.2:** Upon goal creation or modification, the system calculates a **base required monthly contribution**:  
    `(Target Amount – Current Saved) / Number of months remaining until deadline`.  
    For open-ended goals without deadline, prompt user to set a deadline or accept a default 12-month plan.
- **FR2.3:** The system shall analyze the user’s last 3–6 months of transaction data (from PRD-001) to compute:
    - Average Monthly Net Cash Flow = Average Monthly Income – Average Monthly Expenses (excluding goal-related savings transfers).
    - Discretionary Income = Net Cash Flow after mandatory fixed expenses (tagged bills, rent, etc., as marked by user or inferred from recurring high-priority expenses). If not enough data, fall back to simple net cash flow.
- **FR2.4:** The system shall generate a **recommended monthly saving amount** = `max(Base Required, Discretionary Income * 0.5)`, capped at Discretionary Income * 0.8 to avoid overly aggressive plans. This ensures the recommendation respects the user’s actual financial capacity.
- **FR2.5:** If Discretionary Income < Base Required, the system flags the goal as potentially unrealistic and triggers the achievability analysis in PRD-003.
- **FR2.6:** The user can override the recommended amount and set a custom monthly target.

### 3.4 Progress Tracking

- **FR2.7:** Users can manually add progress contributions (date, amount, optional note). These increase Current Saved.
- **FR2.8:** If a linked account exists, the system can automatically detect transfers into that account as progress (optional auto-track).
- **FR2.9:** Dashboard shows each goal’s progress bar, percentage, days remaining, and a warning if behind schedule (based on expected vs. actual contributions).

## 4. Input Form Specification – “Create Goal”

|Field|Input Type|Required|Description|
|---|---|---|---|
|Goal Name|Text|Yes|e.g., “Vacation to Bali”|
|Target Amount|Numeric|Yes|The total amount needed|
|Deadline|Date picker|No|Optional; if not set, system asks for desired monthly amount or defaults to 12 months|
|Priority|Dropdown (High/Med/Low)|Yes|Affects listing order|
|Linked Account|Dropdown|No|Choose a savings account to automatically monitor (optional)|
|Starting balance (already saved)|Numeric|No|Default 0; user can input if they’ve already saved some|

After submission, the system immediately displays:

- Base required monthly amount.
- Smart recommendation based on cash flow analysis.
- User can adjust the recommended monthly amount before saving the goal.

## 5. Non-Functional Requirements

- Recommendation calculation must complete in < 2 seconds, using cached transaction aggregates.
- System must handle currency consistency; all goal amounts in user’s primary currency.

## 6. Success Metrics

- 40% of users who set up accounts (PRD-001) create at least one goal within 30 days.
- 60% of goals have manual contribution logs added monthly.
- Recommendation acceptance rate (user keeps suggested amount or modifies by <10%) > 50%
